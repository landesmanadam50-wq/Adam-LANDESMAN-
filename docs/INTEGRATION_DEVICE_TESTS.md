## לא ניתן לבדוק בלי מכשיר
קומפילציית Kotlin נבדקת בבניית ה־APK. כל ההתנהגויות שלמטה דורשות מכשיר אמיתי.

### A. ARC Addiction
הרשימה המלאה נמצאת ב־`docs/ARC_ADDICTION_MANUAL_TESTS.md`. הסעיפים הקריטיים:
- [ ] התראת "כן / לא" בסוף ההמתנה, בשלושה מצבים: האפליקציה ברקע (התהליך חי), האפליקציה סגורה, והאפליקציה נהרגה. ההתראה צריכה להישאר מוצגת עד שעונים עליה.
- [ ] "לא" פותח את שאלת העוצמה, ו"כן" פותח את תיעוד ההתנהגות. בשני המקרים המסך הקודם לא נמחק.
- [ ] השורה השנייה בטיימר הצף עצמאית מטיימר המשימה, בהשהיה, בהמשך, בסיום ובקיצור של המשימה.

### B. תכנון זמן מחדש
- [ ] משימה שהזמן שהוקצה לה עבר בלי שהתחילה: מגיעה התראת "תכנון זמן מחדש". לחיצה פותחת את מסך Replan.
- [ ] במסך Replan, כרטיס ARC Addiction לא מוצג (כמו ARC GYM / Learning / Creativity), אבל לוח הזמנים והכלים לעריכת היום זמינים.
